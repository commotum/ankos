# 7-PRESET-READY

## Current Facts

- The primitive kernel is the only execution path imported by `ca`.
- The retained suite has nineteen tests covering coordinate selection,
  boundaries, complete immutable execution, compatibility, plural ordinary
  sources, and taxonomy integrity.
- All old execution modules are deleted, not wrapped.
- No canonical preset has been implemented; the flat catalog is an honest
  progress surface.

## Updated Assumptions

- The first future preset can target the first book-ordered family using the
  already tested finite Cartesian behavior.
- More general time, support, and Rule signatures should remain future changes
  driven by the first family that actually needs them.
- Stub honesty is a present-state audit, not a test invariant.

Prove requirement by requirement that Goal 9 ends at a small, executable,
preset-ready kernel rather than at parallel legacy code, ceremony, or a hidden
canonical implementation.

## Stage Results

- **Public composition:** a clean Python process exposed exactly `Space`,
  `SimpleProgram`, `Seed`, `Trajectory`, `Episode`, `step`, `rollout`, and the
  small `selector`, `spaces`, and `catalog` modules. Its import graph contained
  only `ca`, `ca.catalog`, `ca.core`, `ca.selector`, `ca.spaces`, and
  `ca.rollout`.
- **Small value core:** an AST audit found exactly five classes in `core.py`:
  `Space`, `SimpleProgram`, `Seed`, `Trajectory`, and `Episode`. There is no
  inheritance or generic class framework.
- **Selectors:** the retained tests prove ordered offset translation and plain
  Seed-relation selection at `(t, v)` addresses. `selector.py` has functions,
  not locus/region/graph classes.
- **Execution:** anonymous tests prove exact complete successors for Cartesian
  and relational coordinates, fixed versus periodic boundaries, unchanged
  earlier slices, consecutive explicit times, invalid output rejection, and
  two different Seed shapes executing under the same SimpleProgram.
- **Plural sources:** anonymous ordinary generators and nested loops yield
  several definite Spaces, Alphabets, Neighborhoods, Rules, Seeds,
  SimplePrograms, and executable compatible Trajectories without any source
  class.
- **Legacy absence:** final tree and import scans found no `loci.py`,
  `frontiers.py`, alternate old executor, legacy import, proof/capability
  framework, or preset directory.
- **Catalog honesty:** a one-time audit joined all sixty `ref/types.csv` rows
  to the flat catalog in exact order and confirmed that all sixty currently
  raise their exact `NotImplementedError`. This temporary incompleteness is
  intentionally not a permanent test.
- **Meaningful suite:** obsolete ECA, serialization, signature, and catalog-
  implementation theater tests are gone. `uv run pytest -q` reported
  `19 passed in 0.03s` for the retained behavioral and taxonomy-integrity
  suite.
- **Packaging:** `uv build --out-dir <temporary-directory>` successfully
  produced both `ankos-0.2.0.tar.gz` and
  `ankos-0.2.0-py3-none-any.whl`. Wheel inspection contained only the intended
  kernel, flat catalog, typing marker, and independent viewer files.
- **Final hygiene:** `git diff --check` passed. No actual preset, canonical
  implementation, dataset preset, or `presets/` directory exists.

All twelve Success Requirements in `0-plan.md` are satisfied. Goal 9 stops at
the intended boundary. The next honest task is a new goal implementing the
first book-ordered preset from exact documented successor behavior.
