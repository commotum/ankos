Derived-T28-Consequences: With n={2,2}, scalar d=1 applies at both levels. Scalar k=-1 expands to {-1,-1}, then to the same beginning-overhang alignment in both levels. Negative position -1 is the last position, and default padding is cyclic. Therefore the first window has the first old element at its lower-right slot and cyclic predecessors above and left; every old element is the lower-right member of exactly one window. The source underscore is one anonymous Blank that matches any one slot expression. ReplaceAll preserves rule-list priority, while a context matched by no imported rule remains unchanged in the source host expression.
