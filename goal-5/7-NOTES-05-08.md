## No-Cheating Checks

- Page ledgers must advance monotonically and total 90 accounted-for pages in
  each pass. Detector-driven jumps, divided spot checks, or inferred blank
  leaves do not count.
- Every transcription decision must use the fixed-layout PDF. Agreement among
  raw text, split Markdown, PDF extraction, OCR, code, or model confidence is
  not authoritative.
- Preserve errors visibly printed in the source; correct transcription, not
  the author.
- Apply author text and authorial structure only through guarded
  `corrections.jsonl` records. Never hand-edit generated repaired Markdown.
- Never use repaired output as build input; rebuild only from the immutable
  monolith plus compact manifests.
- Inspect all 243 mapped references and every printed visual. Inventory
  presence does not prove completeness, identity, ownership, order, crop, or
  caption association.
- Compare formulas, code, symbolic data, numeric claims, citations, and printed
  references token by token where prose review could miss one meaningful
  character.
- A second pass and each closing pass must inspect the complete post-correction
  document and selected assets, not only corrections or first-pass findings.
- A last correction, display-boundary repair, crop, addition, override, or
  reading-order change forces all affected closing passes to restart from the
  beginning.
- Do not close a document while any source region is unreadable,
  undispositioned, ambiguous, or represented only by a guess.
- Rehash the protected legacy tree and inspect Git scope before closure. Never
  claim human review for agent work.
