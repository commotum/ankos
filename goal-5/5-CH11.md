### Registered mechanics

- `L1545` (`SERIOUS`): a computation interface encodes an abstract input as an
  initial condition, evolves an unchanged system to a time or stopping
  condition, and decodes selected state features. Encoder, observation time,
  and decoder create a construction-versus-use ambiguity (`CH:15-21`, `25-37`).
- `L1546` (`SERIOUS`): a stored-program random-access machine stores data and
  opcodes in addressed bit memory; a program counter fetches, executes,
  increments, or branches. Compilation and interpretation are front ends, not
  separate machines (`N:15-23`).
- `L1547` (`SERIOUS`): a residue-dispatched arithmetic system computes
  `Mod[n,m]`, selects the associated arithmetic function, applies it, and
  repeats. Stage 8 must compare it with earlier number maps (`CH:377-393`;
  `N:525-550`).
- `L1548` (`SERIOUS`): an ordered fraction system chooses the first rational
  multiplier whose product with the current integer is integral, then iterates;
  ordering is defining semantics (`N:552-570`).
- `L1549` (`SERIOUS`): an encoder/evolution/decoder relation maps source states
  into target states, evolves them, and decodes. Fixed, multiple, angled-block,
  and terminating encoders create a relation between mechanisms rather than an
  obviously new dynamical system (`N:674-690`).
- `L1550` (`WEAK`): Gödel-number and Chinese-remainder encodings of finite lists
  are representation infrastructure (`N:781-802`).
- `L1551` (`UNREVIEWED`, later dependency): unbounded minimization returns the
  least nonnegative witness and fails to return when none exists; its partiality
  requires the Chapter 12 halting analysis (`N:829-855`).
