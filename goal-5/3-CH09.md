  and combines the current local result modulo two with the same cell two steps
  back. The source explicitly translates it to a first-order four-color CA, so
  it is state augmentation rather than a distinct primitive (`CH:63-73`;
  `N:25-36`).
- `L1494` (`SERIOUS`): an alternating block CA replaces fixed-size blocks and
  shifts alignment on successive steps; reversibility is a permutation of
  block states and conservation preserves block weight (`CH:303-321`;
  `N:153-165`).
- `L1495` (`WEAK`): an unembedded non-degenerate trivalent graph, with other
  node types encodable as fixed subnetworks, is a support/domain representation
  rather than an executable construction (`CH:491-507`; `N:250-251`).
- `L1496` (`SERIOUS`): a local-template network constraint accepts any complete
  network whose neighborhood around every node matches an allowed template.
  It is an uniterated zero/one/many-answer relation (`CH:595-615`;
  `N:324-330`).
- `L1497` (`SERIOUS`): causal-network extraction makes update events into nodes
  and connects later events to the last events that produced their inputs,
  carrying dependencies through unchanged cells. Whether this is an observer
  or construction-defining output remains open (`CH:655-707`; `N:347-355`,
  `378-384`).
- `L1498` (`RESOLVED`): first-match sequential and maximal left-to-right
  nonoverlap string-rewrite schedules are explicit scheduling variants of
  substitution (`CH:745-769`; `N:363-386`).
- `L1499` (`SERIOUS`): asynchronous CA updates one cell at a time and exposes
  the new value immediately. Scan order, fixed or fresh random permutations,

- `L1500` (`SERIOUS`): arrow states make neighboring CA cells wait until their
  inputs are ready, yielding an intrinsically synchronized asynchronous
  execution protocol (`N:441-443`).
- `L1501` (`RESOLVED`): applying every possible string rewrite and retaining all
  results is explicitly the earlier multiway construction; confluence is a

- `L1502` (`SERIOUS`): a merged-state multiway evolution graph creates one node
  per distinct string and edges for one-step rewrites, raising a

- `L1503` (`SERIOUS`): local graph rewriting replaces a matched connected
  subnetwork while preserving its external interface. Overlapping matches make

- `L1504` (`SERIOUS`): a network mobile automaton keeps one active graph node,

- `L1505` (`SERIOUS`): sample random events in continuous spacetime, connect
